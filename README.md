# Anime Search Engine

A modern and fast web-based application designed for searching anime seamlessly.

## 🚀 Features
- Optimized search performance with a custom debounce mechanism
- Enhanced user experience with dynamic loading indicators
- Smart error management and fallback handling

## 🛠️ Built With
- HTML5 & CSS3
- Vanilla JavaScript
- Git & GitHub Pages
